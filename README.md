# CSU-TAPS data site, 2023 to 2026

Charts and downloads for the CSU-TAPS sprinkler corn data. Data organized by Wub Yilma, Colorado State University.

Access is limited to invited users. Every file in `data/` is encrypted (AES-256-GCM); the site decrypts it in the browser after sign-in. No readable data is stored in this repository.

The site is plain HTML, CSS and JavaScript with no build step and no outside scripts (ECharts and SheetJS are included in `vendor/`).
